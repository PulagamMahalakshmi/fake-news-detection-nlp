# Fake News Detection using NLP and Machine Learning

## Overview

This project focuses on detecting and classifying fake news articles using Natural Language Processing (NLP) and Machine Learning techniques. The system analyzes textual news content and predicts whether the news is REAL or FAKE.

The project includes:

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* TF-IDF Vectorization
* Multiple Machine Learning Models
* Model Evaluation and Comparison
* Prediction System for Real-Time Testing

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* NLTK
* Scikit-learn
* WordCloud

## Machine Learning Models

* Passive Aggressive Classifier
* Logistic Regression
* Multinomial Naive Bayes

## Features

* Fake vs Real News Classification
* NLP-based Text Processing
* Data Visualization and Word Clouds
* Model Performance Comparison
* Confusion Matrix Evaluation
* Prediction System using Custom News Input

## Dataset

The dataset used in this project contains real and fake news articles collected from reliable news sources and is commonly used for NLP and misinformation detection tasks.

## Conclusion

This project demonstrates how NLP and Machine Learning can be used to combat misinformation by automatically identifying fake news articles with strong classification performance.
